# ESP32-CAM Firmware

This folder contains the camera firmware for the Smart IV Infusion Monitoring System.

## Responsibilities
- Capture and stream video of the IV drip chamber.
- Perform motion-based detection of potential drop events.
- Maintain and transmit the detected drop count through the serial interface.

## Setup
Configure the camera board, Wi-Fi settings, and serial communication according to the actual firmware.

**Note:** Upload the tested ESP32-CAM sketch to this folder. Do not publish Wi-Fi passwords or other private credentials.
